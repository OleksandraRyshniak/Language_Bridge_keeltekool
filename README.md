# Language Bridge – Language School Management System

Language Bridge is a web application designed to manage language school courses, teachers, and student registrations.

The project was developed using ASP.NET MVC and C#.

## Features

- User registration and authentication
- Language course management
- Course filtering by language and level
- Teacher and training group management
- Student enrollment in courses
- Registration status management
- Email notifications and communication
- Database operations (CRUD)

## Technologies

- C#
- ASP.NET MVC 5
- .NET Framework 4.7.2
- Entity Framework 6
- SQL Server
- HTML, CSS, JavaScript
- Bootstrap
- ASP.NET Identity

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/OleksandraRyshniak/Language_Bridge_keeltekool.git
   ```
2. Open `Keeltekooli.slnx` in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the database connection.
5. Apply the Entity Framework migrations.
6. Build and run the application.
